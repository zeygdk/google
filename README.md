# 🌐 Google Homepage Clone

A pixel-faithful clone of the **Google homepage** built with **HTML** and **SCSS**, done as a front-end layout exercise.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![Sass](https://img.shields.io/badge/Sass-CC6699?style=flat-square&logo=sass&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## ✨ What's inside

- Top navigation bar (Gmail, Images, apps menu)
- Centered logo, search box and action buttons
- Footer layout
- Styles written in **SCSS** (`main.scss`) and compiled to `main.css`
- Responsive viewport setup

## 🚀 Run

Open `index.html` in any browser.
